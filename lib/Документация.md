## 1. Обзор библиотеки

`yandex_music` — пакет на чистом Dart (работает как в Flutter, так и в обычных Dart-проектах), реализующий доступ к закрытому/недокументированному API сервиса «Яндекс Музыка». Библиотека покрывает большинство популярных функций:

- скачивание треков, включая lossless-качество;
- получение «Моей Волны» (My Vibe / My Wave) и отправка обратной связи (фидбека) по прослушиванию;
- получение информации о треках, альбомах, артистах;
- получение текстов песен (lyrics);
- поиск по трекам, альбомам, артистам, концертам — а также универсальный поиск;
- работа с плейлистами (создание, переименование, удаление, добавление/удаление треков);
- лайки/дизлайки треков;
- загрузка собственных треков пользователя (UGC) и их переименование;
- получение блоков лендинга (главной страницы) — подборки, новинки, чарты и т.д.

Под капотом библиотека использует:

| Зависимость | Назначение |
|---|---|
| `dio` | HTTP-клиент для запросов к API |
| `crypto` | подписи/хэширование запросов |
| `xml` | разбор XML-ответов (используется в части legacy-методов) |
| `mime` | определение MIME-типа при загрузке файлов (UGC-треки) |
| `path` | работа с путями файлов |

Поддерживаемые платформы: Android, iOS, Linux, macOS, Windows (Dart/Flutter SDK).

## 3. Получение OAuth-токена

Для работы с библиотекой обязательно требуется  >OAuth-токен > Яндекс ID.

### 3.1 Рекомендуемый способ (для приложений с интерфейсом)

1. Откройте в `WebView` официальную страницу авторизации Яндекса:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

2. Отследите переход страницы после успешного логина пользователя — в URL будет содержаться `access_token`.
3. Извлеките токен из адресной строки и сохраните его (например, в `flutter_secure_storage`).

Пример с `flutter_inappwebview`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_inappwebview/flutter_inappwebview.dart';

class AuthWebView extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return InAppWebView(
      initialUrlRequest: URLRequest(
        url: WebUri(
          'https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d',
        ),
      ),
      initialSettings: InAppWebViewSettings(javaScriptEnabled: true),
      onLoadStop: (controller, url) async {
        final link = url.toString();
        if (link.contains('access_token')) {
          final token = link.split('#')[1].split('&')[0].replaceAll('access_token=', '');
          print('Получен токен: $token');
        }
      },
    );
  }
}
```

> ⚠️ Важно: ссылка содержит токен во фрагменте URL (`#access_token=...`), а не в query-параметрах, поэтому стандартный перехват по `queryParameters` не сработает — нужно парсить строку вручную, как показано выше.

### 3.2 Альтернативный способ

Существуют сторонние инструкции по самостоятельному получению токена (например, через эмуляцию мобильного клиента). Подробности: https://yandex-music.readthedocs.io/en/main/token.html

> ⚠️ Эти методы не гарантируют, что токен не попадёт в чужие руки — используйте их на свой риск.

## 4. Инициализация и быстрый старт

```dart
import 'package:yandex_music/yandex_music.dart';

final String token = 'y0_4fjegHFFWgn552fnHfjsveegjknavd89UIGFEs';

final YandexMusic yandexMusic = YandexMusic(token: token);

void main() async {
  try {
    await yandexMusic.init(); // обязательная инициализация перед любыми запросами

    final result = await yandexMusic.search.search('Pink Floyd');
    print('Найдено треков: ${result.tracks.length}');
  } on YandexMusicException catch (e) {
    print('Ошибка библиотеки: ${e.type} — ${e.message}');
  }
}
```

Метод `init()` обязателен — он загружает и кэширует базовую информацию об аккаунте (используемую, например, свойствами `accountID`, `account`, `rawUserInfo`). Проверить, прошла ли инициализация успешно, можно через `checkInit()`.

```dart
final bool isReady = await yandexMusic.checkInit();
if (!isReady) {
  await yandexMusic.init();
}
```

## 5. Обработка ошибок (YandexMusicException)

Главный (и единственный) тип исключений библиотеки — `YandexMusicException`. Каждый запрос к API желательно оборачивать в `try/catch`, поскольку даже корректно сформированный запрос может вернуть ошибку (например, если запрашиваемый объект не найден).

### 5.1 Поля класса

| Поле | Тип | Описание |
|---|---|---|
| `message` | `String` | Текст ошибки |
| `code` | `int?` | HTTP-код ошибки (может быть `null`, например для ошибок инициализации) |
| `type` | `YandexMusicExceptionType` | Тип/группа ошибки |

### 5.2 Фабричные конструкторы

| Конструктор | Когда возникает |
|---|---|
| `YandexMusicException(message, type, {code})` | Базовый универсальный конструктор |
| `YandexMusicException.network(message, {code})` | Сетевая проблема (например, недоступен сервер); определяется через `dio` |
| `YandexMusicException.request(message, {code})` | Проблема непосредственно с запросом к серверу |
| `YandexMusicException.unauthorized(message, {code})` | Ошибки авторизации (недействительный/просроченный токен) |
| `YandexMusicException.badRequest(message, {code})` | Ошибка в передаваемых данных запроса |
| `YandexMusicException.notFound(message, {code})` | Запрос выполнен успешно, но сервер не нашёл данных |
| `YandexMusicException.wrongRevision(message, {code})` | Неверная ревизия при изменении плейлиста |
| `YandexMusicException.argumentError(message, {code})` | Передан некорректный аргумент |
| `YandexMusicException.initialization(message)` | Ошибка инициализации библиотеки |

### 5.3 Пример обработки

```dart
try {
  final playlist = await yandexMusic.playlists.getUsersPlaylists();
  print(playlist);
} on YandexMusicException catch (e) {
  switch (e.type) {
    case YandexMusicExceptionType.network:
      print('Сетевая ошибка: ${e.message}');
      break;
    case YandexMusicExceptionType.unauthorized:
      print('Ошибка авторизации: ${e.message}');
      break;
    case YandexMusicExceptionType.badRequest:
      print('Некорректный запрос: ${e.message}');
      break;
    case YandexMusicExceptionType.wrongRevision:
      print('Неверная ревизия плейлиста: ${e.message}');
      break;
    case YandexMusicExceptionType.notFound:
      print('Не найдено: ${e.message}');
      break;
    default:
      print('Другая ошибка: ${e.message}');
  }
} catch (e) {
  // ошибки, не относящиеся к библиотеке
  rethrow;
}
```

## 6. Главный класс YandexMusic

`YandexMusic` — единая точка входа в библиотеку. Через её свойства открывается доступ ко всем функциональным под-модулям API.

### 6.1 Конструктор

```dart
YandexMusic({required String token})
```

### 6.2 Свойства

| Свойство | Тип | Описание |
|---|---|---|
| `token` | `String` (final) | OAuth-токен, переданный при создании |
| `accountID` | `int` | ID текущего аккаунта (кэшируется после `init()`) |
| `rawUserInfo` | `Map<String, dynamic>` | «Сырые» данные пользователя из ответа сервера |
| `account` | `YandexMusicAccount` | Под-модуль для работы с аккаунтом |
| `tracks` | `YandexMusicTrack` | Под-модуль для работы с треками |
| `albums` | `YandexMusicAlbums` | Под-модуль для работы с альбомами |
| `playlists` | `YandexMusicPlaylists` | Под-модуль для работы с плейлистами |
| `usertracks` | `YandexMusicUserTracks` | Под-модуль лайков/дизлайков/загрузки треков |
| `search` | `YandexMusicSearch` | Под-модуль поиска |
| `myVibe` | `YandexMusicMyVibe` | Под-модуль «Моей Волны» |
| `landing` | `YandexMusicLanding` | Под-модуль лендинга |
| `pin` | `YandexMusicPin` | Внутренний класс аккаунта (Account Inner Class) |

> Примечание: классы-«обёртки» (`YandexMusicAccount`, `YandexMusicTrack`, `YandexMusicAlbums` и т.д.) не экспортируются как самостоятельные публичные типы в дартдоке библиотеки — они видны только как типы свойств главного класса `YandexMusic`. Поэтому далее их API описан на основании официального файла `example/lib/example.dart` и README пакета.

### 6.3 Методы

| Метод | Сигнатура | Описание |
|---|---|---|
| `init()` | `Future<void>` | Инициализирует библиотеку: проверяет токен, кэширует данные аккаунта |
| `checkInit()` | `Future<bool>` | Проверяет, была ли успешно выполнена инициализация |

### 6.4 Унаследованные члены (от `Object`)

`hashCode`, `runtimeType`, `noSuchMethod(Invocation)`, `toString()`, `operator ==` — стандартные члены Dart `Object`, отдельного поведения в библиотеке не переопределяют (кроме `toString()` у `YandexMusicException`).

## 7. Модуль account — информация об аккаунте

Доступен через `yandexMusic.account`.

```dart
int accountID = await yandexMusic.account.getAccountID();
// аналогично можно получить через геттер главного класса:
accountID = yandexMusic.accountID;

String email       = await yandexMusic.account.getEmail();
String login        = await yandexMusic.account.getLogin();
String fullName      = await yandexMusic.account.getFullName();
String displayName   = await yandexMusic.account.getDisplayName();
bool? hasPlus        = await yandexMusic.account.hasPlusSubscription();
```

| Метод | Возвращает | Описание |
|---|---|---|
| `getAccountID()` | `int` | Уникальный идентификатор аккаунта |
| `getEmail()` | `String` | Электронная почта аккаунта |
| `getLogin()` | `String` | Логин пользователя |
| `getFullName()` | `String` | Полное имя пользователя |
| `getDisplayName()` | `String` | Отображаемый псевдоним |
| `hasPlusSubscription()` | `bool?` | Наличие активной подписки PLUS (`null`/`false`, если отсутствует) |

Дополнительно (по данным README более ранней версии — могут потребовать проверки в актуальной сборке):

| Метод | Возвращает | Описание |
|---|---|---|
| `getAccountSettings()` | `Map<String, dynamic>` | Настройки аккаунта музыки (тема, громкость, видимость, радио и т.д.) — не из кэша |
| `getAllAccountInformation()` | `Map<String, dynamic>` | Полная необработанная информация об аккаунте — не из кэша |

> Информация об аккаунте кэшируется в момент вызова `yandexMusic.init()`. Если нужно обновить данные — выполните повторную инициализацию.

## 8. Модуль tracks — работа с треками

Доступен через `yandexMusic.tracks`.

### 8.1 Получение информации

```dart
Track track = (await yandexMusic.tracks.getTracks(['330765']))[0];
print('${track.title} — ${track.artists.map((a) => a.title).join(', ')}');

List<Track> similar = await yandexMusic.tracks.getSimilar('330765');
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `getTracks(ids)` | `Future<List<Track>> getTracks(List<String> ids)` | Возвращает полную информацию по списку ID треков (поддерживает прямую передачу `ShortTrack`) |
| `getSimilar(id)` | `Future<List<Track>> getSimilar(String id)` | Похожие треки |
| `getLyrics(id)` | `Future<Lyrics> getLyrics(String id)` | Текст песни (объект `Lyrics`) |

### 8.2 Скачивание треков

```dart
// Скачивание в MP3 320 kbps (по умолчанию)
final bytes = await yandexMusic.tracks.download('330765');

// Скачивание в lossless / выбранном качестве
final losslessBytes = await yandexMusic.tracks.download(
  '330765',
  quality: AudioQuality.lossless,
);

// Запись на диск
final file = File('track.flac');
await file.writeAsBytes(losslessBytes);
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `download(id, {quality})` | `Future<List<int>> download(String id, {AudioQuality quality = AudioQuality.normal})` | Возвращает байты аудиофайла. Качество задаётся через enum `AudioQuality` |

> ⚠️ Трек  >не сохраняется в файл автоматически > — метод возвращает массив байт, и сохранение на диск — задача разработчика.

> Начиная с версии 1.2.2 низкоуровневые методы `Track.getDownloadInfo`, `Track.getAsBytes` и `Track.getAdditionalInfo` скрыты от публичного API — вместо них следует использовать высокоуровневые `download()` и `getLyrics()`.

## 10. Модуль playlists — работа с плейлистами

Доступен через `yandexMusic.playlists`. Для управления конкретным плейлистом используется идентификатор  >kind > — уникальный в рамках пользователя (но не уникальный во всём Яндексе).

> При каждом изменении плейлиста его `revision` увеличивается на 1 — библиотека сама подгружает актуальную ревизию перед изменением, поэтому передавать её вручную, как правило, не требуется.

### 10.1 Чтение плейлистов

```dart
List<Playlist> playlists = await yandexMusic.playlists.getUsersPlaylists();
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `getUsersPlaylists()` | `Future<List<Playlist>>` | Все плейлисты текущего пользователя |
| `getPlaylist(kind, [ownerId])` | `Future<Playlist>` | Информация о плейлисте по `kind`; если плейлист создан другим пользователем — передаётся его `ownerId` |
| `getMultiplePlaylists(kinds)` | `Future<List<Playlist>>` | Несколько плейлистов текущего пользователя сразу |
| `getPlaylists(ids)` | `Future<List<Playlist>>` | Несколько плейлистов от разных владельцев в формате `'ownerId:kind'` |
| `getRecomendationsForPlaylist(kind)` | `Future<List<dynamic>>` | Рекомендации («Моя Волна» для конкретного плейлиста) |

### 10.2 Создание, переименование, удаление

```dart
final newPlaylist = await yandexMusic.playlists.createPlaylist(
  'My Cool Playlist',
  yandexMusic.playlists.publicPlaylist,
);

await yandexMusic.playlists.renamePlaylist(newPlaylist.kind, 'Even Cooler Playlist');
await yandexMusic.playlists.deletePlaylist(newPlaylist.kind);
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `createPlaylist(title, visibility)` | `Future<Playlist>` | Создаёт новый плейлист. Видимость задаётся константами `publicPlaylist` / `privatePlaylist` |
| `renamePlaylist(kind, title)` | `Future<void>` | Переименование плейлиста |
| `deletePlaylist(kind)` | `Future<void>` | Удаление плейлиста |
| `changeVisibility(kind, visibility)` | `Future<void>` | Изменение видимости (`publicPlaylist` / `privatePlaylist`) |

Готовые константы видимости:

```dart
yandexMusic.playlists.publicPlaylist;   // публичный плейлист
yandexMusic.playlists.privatePlaylist;  // приватный плейлист
```

### 10.3 Управление треками в плейлисте

```dart
await yandexMusic.playlists.insertTrack(
  newPlaylist.kind,
  '1234567', // trackId
  '7654321', // albumId
);
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `insertTrack(kind, trackId, albumId, [index])` | `Future<void>` | Вставляет один трек в плейлист на позицию `index` (по умолчанию — 0) |
| `addTracksToPlaylist(kind, tracks, [index])` | `Future<void>` | Вставляет список треков (каждый — `{'trackId': ..., 'albumId': ...}`) за несколько внутренних запросов |
| `deleteTracksFromPlaylist(kind, fromIndex, toIndex)` | `Future<void>` | Удаляет треки из плейлиста по диапазону индексов (не по ID!) |

> ⚠️ Если добавить один и тот же трек дважды — он добавится дважды. Для «перемещения» трека сначала удалите его, затем вставьте на новую позицию.

## 11. Модуль usertracks — лайки, дизлайки, загрузка треков

Доступен через `yandexMusic.usertracks`.

### 11.1 Лайки и дизлайки

```dart
await yandexMusic.usertracks.like(['330765']);
List<ShortTrack> liked = await yandexMusic.usertracks.getLiked();

await yandexMusic.usertracks.unlike(['330765']);
List<dynamic> disliked = await yandexMusic.usertracks.getDisliked();
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `like(ids)` | `Future<void> like(List<String> ids)` | Добавляет треки в «Понравившиеся» |
| `unlike(ids)` | `Future<void> unlike(List<String> ids)` | Убирает треки из «Понравившихся» (не влияет на рекомендации) |
| `getLiked()` | `Future<List<ShortTrack>>` | Список понравившихся треков (только ID, без полной информации) |
| `getDisliked()` | `Future<List<dynamic>>` | Список треков, отмеченных «не рекомендовать» |

> С версии 1.2.2 также доступна возможность добавлять/удалять треки из списка дизлайков (аналогичными по смыслу методами).

> Чтобы получить полную информацию о понравившихся треках (а не только ID), результат `getLiked()` следует передать в `yandexMusic.tracks.getTracks(...)`.

### 11.2 Загрузка собственных треков (UGC)

```dart
final file = File('my_track.mp3');
final trackId = await yandexMusic.usertracks.uploadUGCTrack(3, file); // 3 = kind плейлиста «Мне нравится»

final renamed = await yandexMusic.usertracks.renameUGCTrack(trackId, 'My Track', 'Me');
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `uploadUGCTrack(kind, file)` | `Future<String> uploadUGCTrack(int kind, File file)` | Загружает локальный аудиофайл в библиотеку пользователя, возвращает ID загруженного трека |
| `renameUGCTrack(trackId, title, artist)` | `Future<bool> renameUGCTrack(String trackId, String title, String artist)` | Переименовывает название/исполнителя загруженного трека |

Если система распознаёт загруженный UGC-трек как существующий в каталоге Яндекс Музыки, в объекте `Track` появится заполненное поле `matchedTrack` — ссылка на «настоящий» трек.

## 12. Модуль search — поиск

Доступен через `yandexMusic.search`. У каждого метода поиска можно передать номер страницы (по умолчанию — 0).

```dart
List<Track>  tracks  = await yandexMusic.search.tracks('Pink Floyd');
List<Album>  albums  = await yandexMusic.search.albums('Pink Floyd');
List<Artist> artists = await yandexMusic.search.artists('Pink Floyd');

// Универсальный поиск — лучшие совпадения по всем категориям + список треков
SearchResult result = await yandexMusic.search.search('Pink Floyd');
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `tracks(query, [page])` | `Future<List<Track>>` | Поиск треков |
| `albums(query, [page])` | `Future<List<Album>>` | Поиск альбомов |
| `artists(query, [page])` | `Future<List<Artist>>` | Поиск артистов |
| `search(query, [page])` | `Future<SearchResult>` | Универсальный поиск (новый эндпоинт, добавлен в 1.2.2) — возвращает объект `SearchResult` с лучшими совпадениями по трекам/альбомам/артистам/концертам, а также автокоррекцией опечаток |

> В версии 1.2.2 метод `search.all()` был удалён и заменён универсальным `search.search()`, основанным на новом эндпоинте и возвращающим типизированный объект `SearchResult` (а не «сырой» `Map`, как раньше).

### 12.1 Пример полного разбора `SearchResult`

```dart
void printSearchResultDetails(SearchResult searchResult) {
  print('Запрос: ${searchResult.query}');
  print('Всего найдено: ${searchResult.total}');
  print('Опечатка исправлена: ${searchResult.misspellCorrected}');
  if (searchResult.misspellResult != null) {
    print('Предложенный вариант: ${searchResult.misspellResult}');
  }

  if (searchResult.bestTrack != null) {
    final t = searchResult.bestTrack!;
    print('Лучший трек: ${t.title} (ID: ${t.id})');
  }

  if (searchResult.bestArtist != null) {
    print('Лучший артист: ${searchResult.bestArtist!.name}');
  }

  if (searchResult.bestAlbum != null) {
    print('Лучший альбом: ${searchResult.bestAlbum!.title}');
  }

  if (searchResult.bestConcert != null) {
    print('Лучший концерт: ${searchResult.bestConcert!.concertTitle}');
  }

  for (final track in searchResult.tracks) {
    print('${track.title} — ${track.artists.first.title}');
  }
}
```

## 13. Модуль myVibe — Моя Волна (My Wave)

Доступен через `yandexMusic.myVibe`. Добавлен в версии 1.2.1.

```dart
// Получение доступных настроек волны (жанр/настроение/диктор и т.д.)
List<VibeSetting> settings = await yandexMusic.myVibe.getWaves();

// Создание волны на основе выбранных настроек
Wave wave = await yandexMusic.myVibe.createWave(settings.take(2).toList());

// Отправка обратной связи о прослушивании
await yandexMusic.myVibe.sendFeedback(
  wave,
  SkipFeedback(
    queue: wave.tracks,
    track: wave.tracks[0],
    totalPlayedSeconds: 10.5,
  ),
);
```

| Метод | Сигнатура | Описание |
|---|---|---|
| `getWaves()` | `Future<List<VibeSetting>>` | Список доступных «настроек» волны (жанры, настроения, дикторы и т.п.) |
| `createWave(settings)` | `Future<Wave> createWave(List<VibeSetting> settings)` | Создаёт сессию волны на основе переданных настроек |
| `sendFeedback(wave, feedback)` | `Future<void> sendFeedback(Wave wave, MyVibeFeedback feedback)` | Отправляет обратную связь по прослушиванию (см. подтипы `MyVibeFeedback` ниже) |

### 13.1 Виды обратной связи (`MyVibeFeedback`)

`MyVibeFeedback` — абстрактный базовый класс. Используются три его реализации:

| Класс | Конструктор | Когда отправлять |
|---|---|---|
| `TrackStartedFeedback` | `TrackStartedFeedback({required Track track})` | Когда начато воспроизведение трека |
| `SkipFeedback` | `SkipFeedback({required Track track, required double totalPlayedSeconds, required List<Track> queue})` | Когда трек был пропущен (skip) |
| `TrackFinishedFeedback` | `TrackFinishedFeedback({required Track track, required double totalPlayedSeconds, required List<Track> queue})` | Когда трек был прослушан до конца |

## 17. Вспомогательные классы

### 17.1 `CancelToken`

Управляет отменой запросов библиотеки `dio`, использующейся под капотом. Один и тот же токен можно передать нескольким запросам — вызов `cancel()` отменит их все.

| Член | Тип/сигнатура | Описание |
|---|---|---|
| `isCancelled` | `bool` | Был ли токен отменён |
| `cancelError` | `DioException?` | Ошибка отмены (если была) |
| `requestOptions` | `RequestOptions?` | Опции соответствующего запроса |
| `whenCancel` | `Future<DioException>` | Future, резолвящийся при отмене |
| `cancel([reason])` | `void cancel([Object? reason])` | Отменяет запрос(ы), связанные с токеном |
| `CancelToken.isCancel(error)` | `static bool isCancel(DioException error)` | Проверяет, была ли ошибка вызвана отменой |

## 18. Полный пример example.dart

Ниже приведён актуальный (версия 1.2.2) пример использования библиотеки из официального репозитория, демонстрирующий все основные модули API.

```dart
import 'package:yandex_music/yandex_music.dart';

final String token = 'token';

YandexMusic yandexMusic = YandexMusic(token: token);

void main() async {
  try {
    await yandexMusic.init();
    SearchResult result = await yandexMusic.search.search('i want brek free'); // опечатка специально
    printSearchResultDetails(result);
  } on YandexMusicException catch (e) {
    switch (e.type) {
      case YandexMusicExceptionType.network:
        print('Network error: ${e.message}');
        break;
      case YandexMusicExceptionType.unauthorized:
        print('Token invalid: ${e.code} ${e.message}');
        break;
      case YandexMusicExceptionType.wrongRevision:
        print('Playlist revision mismatch');
        break;
      default:
        print('Other error: ${e.message}');
    }
  }
}

void accountInfo(YandexMusic yandexMusic) async {
  int accountID = await yandexMusic.account.getAccountID();
  accountID = yandexMusic.accountID; // альтернативный способ
  String email = await yandexMusic.account.getEmail();
  String login = await yandexMusic.account.getLogin();
  String fullName = await yandexMusic.account.getFullName();
  String displayName = await yandexMusic.account.getDisplayName();
  bool? plusSubscription = await yandexMusic.account.hasPlusSubscription();

  print('Email: $email');
  print('Login: $login');
  print('Full name: $fullName');
  print('Account ID: $accountID');
  print('Display name: $displayName');
  print('Plus subscription state: $plusSubscription');
}

void trackExamples(YandexMusic yandexMusic) async {
  Track track = (await yandexMusic.tracks.getTracks(['330765']))[0];
  print('Track: ${track.title} by ${track.artists.map((a) => a.title).join(', ')}');

  var bytes = await yandexMusic.tracks.download('330765');
  print('Downloaded ${bytes.length} bytes');

  var losslessBytes = await yandexMusic.tracks.download('330765', quality: AudioQuality.lossless);
  print('Lossless size: ${losslessBytes.length} bytes');

  Lyrics lyrics = await yandexMusic.tracks.getLyrics('330765');
  print('Lyrics: ${lyrics.downloadUrl}');

  List<Track> similar = await yandexMusic.tracks.getSimilar('330765');
  print('Similar tracks: ${similar.length}');
}

void albumExamples(YandexMusic yandexMusic) async {
  Album album = await yandexMusic.albums.getInformation(3389005);
  print('Album: ${album.title} by ${album.artists.map((a) => a.title).join(', ')}');

  List<Album> albums = await yandexMusic.albums.getAlbums([3389005]);
  print('Fetched ${albums.length} albums');
}

void playlistExamples(YandexMusic yandexMusic) async {
  List<Playlist> playlists = await yandexMusic.playlists.getUsersPlaylists();
  print('User has ${playlists.length} playlists');

  Playlist newPlaylist = await yandexMusic.playlists.createPlaylist(
      'My Cool Playlist', yandexMusic.playlists.publicPlaylist);
  print('Created playlist: ${newPlaylist.title} (kind: ${newPlaylist.kind})');

  await yandexMusic.playlists.insertTrack(newPlaylist.kind, '1234567', '7654321');
  print('Track added');

  await yandexMusic.playlists.renamePlaylist(newPlaylist.kind, 'Even Cooler Playlist');

  await yandexMusic.playlists.deletePlaylist(newPlaylist.kind);
  print('Playlist deleted');
}

void likeExamples(YandexMusic yandexMusic) async {
  await yandexMusic.usertracks.like(['330765']);
  print('Track liked');

  List<ShortTrack> liked = await yandexMusic.usertracks.getLiked();
  print('Liked tracks: ${liked.length}');

  await yandexMusic.usertracks.unlike(['330765']);
  print('Track unliked');

  List<dynamic> disliked = await yandexMusic.usertracks.getDisliked();
  print('Disliked tracks: ${disliked.length}');
}

void searchExamples(YandexMusic yandexMusic) async {
  List<Track> tracks = await yandexMusic.search.tracks('Pink Floyd');
  print('Found ${tracks.length} tracks');

  List<Album> albums = await yandexMusic.search.albums('Pink Floyd');
  print('Found ${albums.length} albums');

  List<Artist> artists = await yandexMusic.search.artists('Pink Floyd');
  print('Found ${artists.length} artists');

  var all = await yandexMusic.search.search('Pink Floyd');
  printSearchResultDetails(all);
}

void vibeExamples(YandexMusic yandexMusic) async {
  List<VibeSetting> settings = await yandexMusic.myVibe.getWaves();
  print('Available vibe settings: ${settings.length}');

  Wave wave = await yandexMusic.myVibe.createWave(settings.take(2).toList());
  print('Wave created: ${wave.batchId}');

  List<Track> queue = wave.tracks;
  await yandexMusic.myVibe.sendFeedback(
    wave,
    SkipFeedback(
      queue: queue,
      track: wave.tracks[0],
      totalPlayedSeconds: 10.5,
    ),
  );
  print('Skip feedback sent');
}

void uploadExamples(YandexMusic yandexMusic) async {
  File file = File('my_track.mp3');
  String trackId = await yandexMusic.usertracks.uploadUGCTrack(3, file);
  print('Uploaded track ID: $trackId');

  bool renamed = await yandexMusic.usertracks.renameUGCTrack(trackId, 'My Track', 'Me');
  print('Renamed: $renamed');
}

void printSearchResultDetails(SearchResult searchResult) {
  print('Query: ${searchResult.query}');
  print('Total: ${searchResult.total}');
  print('Per Page: ${searchResult.perPage}');
  print('Last Page: ${searchResult.lastPage}');
  print('Misspell Corrected: ${searchResult.misspellCorrected}');
  if (searchResult.misspellResult != null) {
    print('Suggested: ${searchResult.misspellResult}');
  }

  if (searchResult.bestTrack != null) {
    final t = searchResult.bestTrack!;
    print('BEST TRACK: ${t.title} (ID: ${t.id})');
    print('  Source: ${t.trackSource.name}');
    if (t.artists.isNotEmpty) {
      for (final artist in t.artists) {
        if (artist is OfficialArtist) {
          print('    - ${artist.title} (composer: ${artist.composer})');
        }
      }
    }
    if (t.matchedTrack != null) {
      print('  Matched UGC track: ${t.matchedTrack!.title}');
    }
  }

  if (searchResult.bestArtist != null) {
    print('BEST ARTIST: ${searchResult.bestArtist!.name}');
  }

  if (searchResult.bestAlbum != null) {
    print('BEST ALBUM: ${searchResult.bestAlbum!.title}');
  }

  if (searchResult.bestConcert != null) {
    final c = searchResult.bestConcert!;
    print('BEST CONCERT: ${c.concertTitle} (${c.city}, ${c.dateTime})');
  }

  print('TRACKS LIST (${searchResult.tracks.length}):');
  for (final tr in searchResult.tracks) {
    print('${tr.title} — ${tr.albums.isNotEmpty ? tr.albums[0].title : ''} — '
        '${tr.artists.isNotEmpty ? tr.artists[0].title : ''}');
  }
}
```

### Дисклеймер

Библиотека является  >неофициальной > и использует недокументированный/закрытый API Яндекс Музыки. Сервис может в любой момент изменить поведение своего API, что может нарушить работу части методов библиотеки. Используйте токен авторизации ответственно — он даёт полный доступ к вашему аккаунту Яндекс ID.
